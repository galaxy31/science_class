# 달 관측실 · 위상과 자전

설치·외부 라이브러리 없이 실행하는 한국어 과학 수업용 HTML 앱입니다.

## 실행

- `index.html`을 내려받아 브라우저로 열면 인터넷 없이 실행됩니다.
- 저장소의 지구과학 도구 목록에서 **달 관측실 · 위상과 자전**을 선택할 수 있습니다.
- `index.html#rotation`으로 열면 자전 비교 페이지부터 시작합니다.

## 1. 위상 변화

- 교과서와 같은 배치: 태양은 오른쪽, 달은 반시계 방향으로 공전합니다.
- 궤도 클릭·드래그, 슬라이더, 8개 대표 위상 선택, 자동 재생을 지원합니다.
- 노란 평행 광선은 달의 태양 쪽 표면에서 끝납니다. 하늘색은 사람이 바라보는 방향입니다.
- 밤 쪽 관측자는 자동으로 이동하거나 18시·21시·0시·3시·6시로 고정할 수 있습니다. 12시는 낮과 비교하는 옵션입니다.
- 지평선 아래의 달은 관측 불가로 표시하고 시선을 파선으로 구분합니다.
- 삭은 밤에 볼 수 없으며, 관측 불가 상황의 오른쪽 그림은 비교용 위상 모형입니다.

## 2. 같은 면을 보는 이유

- 실제 달(공전 1회 = 자전 1회)과 가상의 달을 나란히 비교합니다.
- 자전 없음·자전 2회 조건을 바꿀 수 있습니다.
- A와 반대편 B를 표시해 공전 진행에 따른 지구 쪽 표면을 확인합니다.
- 약 27.3일의 공전·자전 주기와 약 29.5일의 위상 주기를 구별합니다.

## 수업과 조작

전체 화면, 교사용 탐구 순서, 모형의 범위 설명을 제공합니다. 마우스·터치용 Pointer Events, 키보드 방향키, 모바일 반응형 레이아웃을 적용했습니다. 페이지를 바꾸면 재생이 멈춥니다. 자전 재생은 1바퀴에서 정지합니다.

## 모형의 범위

실제 크기·거리 비율, 위도·계절, 궤도 경사, 식 현상, 대기 굴절, 시차, 칭동을 생략한 수업 모형입니다. 시간은 개념적 지방 태양시이며 실제 한국 표준시의 출몰 시각을 예측하지 않습니다. 위상 그림은 달의 북쪽을 위로 둔 모형이고 실제 하늘의 기울기는 다를 수 있습니다. 달 표면 무늬는 자체 제작한 개념 표현입니다. 첨부 교과서 사진은 재배포하지 않습니다.

## 검증

JavaScript 문법, 8개 대표 위상, 밝은 면의 비율과 좌우 방향, 720개 자동 관측 위치, 자정의 관측 가능 여부, 동주기 자전, 광선의 달 표면 도달 좌표, HTML ID와 외부 의존성 여부를 검사했습니다. 모의 DOM/Canvas로 위상 버튼·관측 시간·재생·페이지 전환·자전 비교·초기화·안내 창의 코드 실행도 검사했습니다.

실제 브라우저의 화면 배치·터치 동작 확인은 실행 환경 연결 중단으로 완료하지 못했습니다.
