# 과학 수업 도구 모음 (science_class)

중학교 과학 수업 시간에 전자칠판이나 학생 기기에서 바로 열어 쓰는 웹 도구 모음입니다.
설치 없이 브라우저에서 열립니다.

**바로 열기:** https://galaxy31.github.io/science_class/

## 분야별 도구

| 분야 | 주소 | 도구 |
|---|---|---|
| 물리학 | [/physics/](https://galaxy31.github.io/science_class/physics/) | 준비 중 |
| 화학 | [/chemistry/](https://galaxy31.github.io/science_class/chemistry/) | 준비 중 |

## 도구 추가하는 법

1. `분야폴더/도구이름/index.html` 로 파일을 올립니다.
2. `assets/tools.js`의 목록에 한 항목을 추가하면 첫 화면과 분야 페이지에 카드가 자동으로 생깁니다.

자세한 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다.
